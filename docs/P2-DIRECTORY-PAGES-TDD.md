## 用户可见行为

书桌每页显示 100 项，分页按钮在长列表上方；目录在前，文件名按稳定顺序排列。当前目录名称筛选覆盖全部页，清空筛选回到第一页。目录内容变化使旧游标失效，界面明确提示并回到第一页；正文编辑不改变目录成员时可以继续原分页。

目录树按需展开，每个分支每页 25 个目录；每次只呈现当前页，最多展开 64 个目录和 16 层。名称按钮可以直接浏览目录，路径按钮可返回任意祖先，“上一级”保持在已授权范围内。文件变化刷新树的内容并保留正在展开的分支；新工作台清空旧树、页和筛选。长文件列表不会把树挤成不可读的高度。

`list_files` 与书桌共用服务：`path`、`query`、`kind=all/directories`、`limit=1..500`、`cursor`。返回 `entries/total/offset/nextCursor/truncated`；下一页使用相同目录和筛选。游标绑定会话、目录、工作台、授权和目录快照，不能跨范围继续。系统拒绝读取、目录消失、读取超时和预算超限有明确错误，系统原始诊断路径不直接外泄。

- 每个目录请求最多扫描 20000 项或 8 MiB 文件名，约 5 秒在文件系统操作之间检查；超限或目录读取途中变化时拒绝返回看似完整的页。没有磁盘索引，系统阻塞调用不保证即时中断。
- 单根工作台的有界目录树已实现；多根目录同时展开、最近工作区属于 CA-WORK-001 的未完成范围。
- 私有目录与撤销路径被隐藏；链接和特殊项目在普通列表中禁用，不进入目录树。授权不等于系统沙盒。
- 仅本机 Windows 临时夹具验证。系统拒绝访问的错误注入、文件名预算与目录快照替换属于可控测试；真实 ACL 矩阵、网络盘、跨平台、长期压力与持续路径替换攻击未专项验证。
