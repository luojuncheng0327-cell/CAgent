## P1 · 启动、桌面与初始化（BOOT）

程序怎么启动：主窗口、托盘、首次设置、系统文件选择框、快捷键等桌面外壳。待实现 9 项：🟡 4、⬜ 5。

### 🟡 CA-BOOT-002 桌面进程与主窗口

- 入口：Windows 应用启动
- 输入 → 输出：用户启动 → 一个可用主窗口和服务实例
- 验收要点：连续启动两次只聚焦一个实例；服务崩溃后恢复不丢会话
- 已有：只允许运行一个实例，再次启动会聚焦已有窗口；本机服务随窗口启动；页面崩溃后自动重新载入。
- 还缺：本机服务和主窗口在同一进程，进程崩溃后要手动重开；“服务崩溃后恢复不丢会话”还没有专项验证。

### 🟡 CA-MODEL-005 发现模型与连通性测试

- 入口：获取模型 / 测试按钮
- 输入 → 输出：供应商配置 → 模型清单或结构化诊断
- 验收要点：模型列表为空不能报网络失败；测试结果包含协议和脱敏目标

### 🟡 CA-MODEL-006 模型元数据编辑

- 入口：模型详情
- 输入 → 输出：模型 ID、上下文、最大输出、价格、模态、推理档位 → 保存结果
- 验收要点：新增、修改、删除后列表同步；覆盖字段重启不丢
- 已有：模型详情可以编辑显示名称、模型 ID、上下文窗口、最大输出、推理档位和默认档位、出站参数映射、三种价格、是否允许工具调用和是否支持图片。
- 还缺：除图片外的其他模态（音频、视频）还不能声明；增删改后的列表同步和重启保持还没有专项验证。

### 🟡 CA-MODEL-007 模型职责分配

- 入口：助手和通用模型设置
- 输入 → 输出：聊天、轻量任务、复杂任务、embedding、视觉模型 → 独立选择
- 验收要点：修改辅助模型不改变聊天模型；会话覆盖不污染其他会话
- 已有：每个会话可以在分组菜单里选模型，推理档位跟着联动；首次引导可保存小工具 / 大工具模型职责引用，重启后恢复选择。保存、重新载入和生成中锁定都有桌面测试。
- 还缺：辅助模型自动任务分工、embedding 和视觉职责调用还没有；跨会话互不影响的完整情形还没验证。

### 🟡 CA-MODEL-010 重试与预算

- 入口：单次模型执行
- 输入 → 输出：超时、最大输出、重试上限 → 有界执行
- 验收要点：同一失败最多按设定重试，停止后请求数不再增长；不暗降模型
- 已有：请求超时、最大输出和最大工具轮数可以设置；手动重试会另开分支，并禁止重放写入类工具。
- 还缺：网络失败时的自动重试策略（次数上限和停止条件）还没有。

### 🟡 CA-MODEL-012 模态与兼容性

- 验收要点：文本模型不接收伪装图片；辅助结果带原始附件引用
