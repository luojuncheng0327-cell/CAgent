当前阶段：功能规格已冻结（210 项），独立实现进行中，还不是可以发布的完整产品。

## 本地运行

需要 Node.js 24.14+（24.x）和 pnpm 11。首次安装并启动：

```powershell
pnpm install --frozen-lockfile
pnpm run setup:desktop
pnpm run build
pnpm start
```

默认数据目录是用户目录下的 `.cagent`，和旧程序的数据互不相干，不会自动导入旧配置或密钥。开发时请用 `CAGENT_HOME` 指定一个单独的目录：

```powershell
$env:CAGENT_HOME = Join-Path (Get-Location) '.runtime\development'
pnpm start
```

- 只启动本机服务：`pnpm dev`。命令行：`pnpm cli -- status`、`pnpm cli -- sessions`、`pnpm cli -- chat`。
- 服务只监听 `127.0.0.1`，连接信息写在数据目录的 `connection.json`，不要把这个文件发给别人。

## 验证

```powershell
pnpm run verify
pnpm run test:desktop
pnpm run status
```

- `verify`：格式、生成文件是否最新、类型、单元测试、构建、独立性检查、相似度检查。改完代码先运行 `pnpm run format`，因为第一步就是格式检查。
- `test:desktop`：在真实 Electron 窗口里跑桌面测试，期间会闪出窗口和确认框，由测试自己处理，不要去点。
- `status`：改完进度台账 `spec/progress.mjs` 后，重新生成状态 JSON、功能实现情况和待实现功能清单。
- 测试只用临时数据和本机模型夹具，不读旧配置，不调用收费模型。
- `check:independent` 核对 import、依赖和原目录的文件指纹；`check:similarity` 把代码和文字与原版逐段比对，越过限值就失败，报告写在本机 `.artifacts/`（含原版片段，不提交）。两者都不是法律鉴定。属于公共约定的重合登记在 `scripts/similarity-exceptions.json`。
- 完整产品的发布门禁 `node scripts/release-gate.mjs` 在清单还有未完成项时会一直阻止发布。

## 已经能用的

- 模型：五种协议的独立实现，供应商和模型配置，系统加密保存的密钥，推理档位，用量和费用统计。
- 聊天：流式回复和停止，思考与工具过程，Markdown 排版，文本 / 图片 / PDF / DOCX 附件；可以选择、拖入或粘贴文件。图片完整解码，文档在本机提取文字，损坏、空文档和超限会报错；部分 PDF 页无文字时同时向用户和模型提示。支持编辑 / 重试 / 分叉，手动和实验自动分批压缩；会话全文搜索、命中片段与分页、历史消息定位和 Ctrl+F 会话内查找，手动和置顶排序、归档和导出；四个执行任务加六十四个等待位置。
- 书桌：每会话最多授权 16 个目录，逐个设置只读 / 读写并切换当前工作台；普通目录分页、按需展开的目录树与路径导航，当前目录筛选覆盖全部页，可递归搜索全部文件名或 UTF-8 正文，点击正文结果定位源码行，截断和跳过情况可见。多标签编辑，Markdown 直接编辑；眼睛图标切换预览，“更多”菜单选择文档 / 源码，手动保存或 Ctrl+S；外部修改提醒，文件历史恢复。文件恢复草稿自动保存到应用数据目录，重启恢复已落盘的修改、标签与位置，源文件仍需手动保存。文件列表的“⋯”可管理文件和目录，支持跨授权根移动、二进制文件复制、上传及确认后移入系统回收站。
- 文件工具：`file_info` 获取当前文件或目录 SHA-256；`copy_file` 复制授权文件原字节，`list_attachments` 列本会话附件编号，`materialize_attachment` 保存原附件到授权工作区；复制和保存均不覆盖同名目标。`find_files` 按 glob 查找授权目录，`search_files` 按字面正文检索并可过滤文件，返回路径和行号；`read_file` 可按包含末行的行范围或字符偏移读取，原换行和文件 SHA-256 保留，截断时提供续读位置。
- 安全：本机接口鉴权，只读 / 询问 / 操作三种权限，执行前逐次确认，工作区越界拦截；目录撤销后重新检查待执行操作，撤销子目录不会重新继承父目录权限。
- 数据：独立数据目录，事务写入，崩溃恢复，含附件原始字节的中立备份 v3，兼容导入 v1 / v2；导入重新校验图片并从文档重建提取文字，失败不产生部分导入。中断的工具结果明确标为未知，重试不会重新写文件。
- 界面：暖纸 / 青夜 / 跟随系统主题，5 款官方字体，自绘图标，模型 / 推理 / 权限选择菜单；简中、繁中、英文、日文、韩文覆盖引导与当前主界面，设置中可切换语言和时区，重启保持。
- 资料：用户和每个助手分别编辑名字、简介与头像；上传 PNG / JPEG / GIF / WebP，在本机预览缩放与裁剪，保存为 256×256 静态 PNG。默认主助手仍使用维护者提供的图片，其他身份回退首字头像。用户简介作为背景发送给对话模型，头像不发送给模型。
- 首次使用：语言、称呼与记忆、供应商、模型、工作台、完成页六步；分步保存和重启恢复，最后用事务创建配置与首个会话。选择的语言同时应用到主界面。

使用上限：聊天附件每个 4 MiB、每条最多 8 个共 16 MiB，文本附件或文档提取文字 512 KiB 以内；图片边长不超过 8192、最多 120 帧、全部帧合计不超过 16777216 像素；PDF 最多 200 页，DOCX 解压后合计 16 MiB、单项 8 MiB、最多 1024 项。文档只发送提取文字，不含图片、原排版或 OCR。图片与 PDF/DOCX 文字预览每文件最多 4 MiB；可编辑 2 MiB 以内的 UTF-8 文本文件；每个会话工作区最多 10 个文件标签，恢复草稿与原文合计 8 MiB。工作区上传 / 单文件操作最多 16 MiB，目录操作最多 32 MiB、1024 项、32 层；跨磁盘移动尚未提供。最多 4 个会话同时运行，另有 64 个等待位置。恢复草稿约 350 ms 防抖保存，硬退出前尚未落盘的末尾文字不能保证恢复。
