## 用起来，也像你自己

<p align="center">
  <img src="docs/assets/readme-appearance.svg" alt="外观插图：暖纸与青夜两种氛围，以及中、繁、EN、日、한五种界面语言" width="100%" />
</p>

**白天的暖纸，夜里的青色。** 暖纸、青夜与跟随系统主题，搭配可选字体和字号，让桌面适应你的阅读习惯。

**熟悉的语言，自己的形象。** 简体中文、繁体中文、英语、日语、韩语随时切换；为自己和助手设置头像与称呼，让日常交流更亲切。

## 自己的工作台，自己做主

| 你的内容 | 你的模型 | 你的文件 |
|:---:|:---:|:---:|
| 会话、配置与草稿默认保存在本机 | 自由配置模型服务与接口 | 按目录授权，选择文件访问范围 |
| 继续上次的思路，也保留自己的节奏 | 按照当前任务，选择合适的搭档 | 手动保存，让每一次改动心中有数 |

<p><sub>使用远程模型时，发送的消息、附件内容与工具结果会交给你选择的模型服务处理。</sub></p>

## 把 CAgent 放到桌面上

1. **下载安装** — 在[发布页](https://github.com/luojuncheng0327-cell/CAgent/releases/tag/v0.2.1)选择 `CAgent-0.2.1-Windows-x64-Setup.exe`。
2. **连接模型** — 跟随首次引导，填写模型接口和 API Key。
3. **开始工作** — 发起一次对话，添加资料，或打开工作台里的文件。

安装时可选择位置，后续可在应用内检查、下载与安装更新。
